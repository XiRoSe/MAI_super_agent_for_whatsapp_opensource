# Support

Mai is a solo-maintained project. Support is **best-effort, with no SLA** —
responses can take days.

| I want to... | Go to |
| --- | --- |
| Ask a question / get self-hosting help | [GitHub Discussions](https://github.com/XiRoSe/MAI_super_agent_for_whatsapp_opensource/discussions) |
| Report a reproducible bug | [New issue → Bug report](https://github.com/XiRoSe/MAI_super_agent_for_whatsapp_opensource/issues/new/choose) |
| Suggest a feature | [Discussions → Ideas](https://github.com/XiRoSe/MAI_super_agent_for_whatsapp_opensource/discussions) (small, well-scoped requests can use the feature-request issue form) |
| Report a security issue | [SECURITY.md](SECURITY.md) — privately, please |

**Issues are for bugs with reproduction steps.** Questions filed as issues will
be converted to Discussions.

Before asking, please:

- search existing issues and discussions;
- include your Mai version (git SHA or release tag), deployment method
  (compose / Railway / other), and gateway (mai-gowa) version;
- attach relevant logs (`docker compose logs --tail=200 mai gowa`) with phone
  numbers, tokens, and message content redacted.

WhatsApp account warnings/bans are outside anyone's control here — see
[DISCLAIMER.md](DISCLAIMER.md) before asking about those.
